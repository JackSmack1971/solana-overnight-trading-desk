# Ordered development gates

P0: qualify installed Codex and host; capture baseline and lock blueprint. P1: contract inventory, requirement IDs, schemas, fixtures. P2: pure deterministic application core. P3: offline providers/decoders and independent reference parity. P4: paper engine, ledger and recovery. P5: reports and experiment protocol. P6: offline acceptance and negative tests. P7: operator-controlled WSL2 qualification. No phase promotion from prose alone. The blueprint's §16–18 is normative for sequencing and acceptance.
